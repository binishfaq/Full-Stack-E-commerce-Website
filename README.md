# 🛒 EaseShop – Full Stack E-Commerce Website

EaseShop is a full-featured e-commerce web application built using **HTML, CSS, Vite (Frontend), Node.js, Express.js, and MySQL**, with a complete **Admin Panel** for product and order management.

---

## 🚀 Features

### 👤 User Side
- Product browsing with categories
- Product detail page
- Add to cart & remove items
- Checkout system
- Order placement
- Responsive UI (mobile + desktop)

### 🛠 Admin Panel
- Add / Edit / Delete products
- Manage categories
- View all orders
- Update order status
- Dashboard with basic stats

---

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Admin Panel:** Custom built (Express + Frontend UI)
- **API:** RESTful APIs
